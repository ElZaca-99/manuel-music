# 🎵 Manuel Music

Tu buscador y descargador de música personal. Busca canciones en YouTube y descárgalas en MP3 directamente desde tu navegador.

## ✨ Características

- 🔍 **Buscador inteligente** en YouTube
- ⬇️ **Descarga directa** en formato MP3 de alta calidad
-  **Diseño responsive** (funciona en PC y móvil)
- 🎨 **Interfaz moderna** tipo Spotify
-  **Desplegado en Railway** para acceso desde cualquier lugar

## 🛠️ Tecnologías

- **Backend:** Node.js + Express
- **Frontend:** HTML5 + CSS3 + JavaScript
- **Descargas:** yt-dlp + ffmpeg
- **Deploy:** Docker + Railway
